# Rick & Morty Character Explorer

Aplikasi Flutter untuk menjelajahi karakter dari serial Rick and Morty dengan integrasi The Rick and Morty API, sqflite, shared_preferences, dan provider.

## Fitur
- Login & Register dengan SQLite (`sqflite`) & Session (`shared_preferences`)
- Daftar Karakter & Infinite Scroll Pagination
- Pencarian Karakter & Filter Status (Alive, Dead, unknown)
- Detail Karakter
- Favorit Tersinkronisasi Realtime & Swipe-to-Dismiss
- Daftar Seluruh Episode (51 Episode)
- Tema Gelap Rick & Morty dengan Portal Green `#97CE4C`

## Menjalankan Aplikasi
```bash
flutter pub get
flutter run
```
